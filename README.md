# PamGene Data Analysis Guide

Documentation for PamGene kinase activity data analysis using Tercen.

Published at: https://pamgene.github.io/PamGene_data_analysis_guide/

Development notes:

If using Claude: ask it to build, commit and deploy. It will verify if everything is done in the right way.

In conda:

To preview:
```
mkdocs serve
```

To publish:
```
mkdocs gh-deploy
```
